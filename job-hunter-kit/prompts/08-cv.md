# Fase 08 · CV a medida

## Contexto
Lee `docs/POLICIES.md` §1, §3 y §4, `docs/AGENT_INTERFACE.md` (`CvContent`, `CvVerification`),
`docs/DECISIONS.md` ADR-004 y los roles `.agents/roles/redactor.md` y `verificador.md`.

## Objetivo
De una oferta aprobada, un DOCX + PDF fieles a tu diseño, sin nada inventado y verificados.

## Alcance
1. **Plantilla**: `demo/cv_template.docx` sencilla y limpia, creada con `python-docx` y
   marcadores `docxtpl` (subtítulo, resumen, bucles de experiencia, bullets, skills por grupo,
   educación, idiomas, foto condicional con `InlineImage`). Documenta en
   `docs/CV_TEMPLATE.md` cómo marcar la plantilla propia del usuario a partir de su Word:
   qué marcadores existen y cómo evitar que Word parta un marcador en varios fragmentos
   (escribirlo de una vez, sin autocorrección).
2. `app/services/documents/cv_render.py`: `CvContent` + perfil → contexto → docxtpl →
   `data/cvs/<job_id>-<empresa>-<lang>-v<n>.docx`.
3. `app/services/documents/pdf.py`: LibreOffice headless con `SOFFICE_PATH` o las rutas típicas
   de Windows; como alternativa, conversión con Word vía `docx2pdf` si está instalado. Timeout,
   un directorio de perfil de LibreOffice temporal por conversión y limpieza garantizada.
4. `app/services/documents/checks.py`: páginas con `pypdf`; cobertura de keywords
   (`must_have_skills` presentes en el texto extraído del PDF); validación de evidencias, de
   skills fuera del perfil y de `basic_skills` no pedidas (POLICIES §1). Si el contenido viola
   algo, `save_cv_content` falla con errores accionables. Si excede `max_pages`, se guarda igual
   pero con aviso `too_long` para que el agente recorte.
5. Interfaz para agentes (MCP y CLI): `save_cv_content`, `get_cv_content` y `save_cv_verification`. `cv_verified` con
   `passed=true` lleva a `cv_ready`.
6. UI: en la ficha, sección "Documentos" con versiones, estado de verificación, avisos, páginas,
   cobertura y enlaces para abrir el DOCX o el PDF. La API sirve los ficheros solo desde `data/cvs/`.
7. `jh doctor` comprueba ahora también la conversión a PDF con la plantilla demo.

## Fuera de alcance
Cartas y respuestas de screening (fase 10), envío (fase 11).

## Criterios de aceptación
- Tests: render con el perfil demo, rechazo por evidencia inexistente, rechazo por skill básica
  no pedida, detección de dos páginas.
- La conversión funciona en Windows con LibreOffice instalado (probar manualmente).
- Flujo completo: aprobar una oferta → skill `generar-cv` con su id → PDF de una página verificado → etapa `cv_ready`.

## Al terminar
Actualiza `docs/ROADMAP.md`. Indica al usuario cómo preparar su plantilla real siguiendo
`docs/CV_TEMPLATE.md` y dónde dejarla (`data/cv_template.docx`).
