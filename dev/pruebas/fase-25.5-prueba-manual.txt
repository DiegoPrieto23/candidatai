Fase 25.5 · Maquetación del PDF: prueba manual
==============================================

Qué se prueba: que los avisos de maquetación del CV y la carta salen con tus CVs reales y tus
plantillas (también las importadas), con la página y cómo arreglarlo, y que no salen falsos
positivos. Los tests usan PDFs de prueba y la demo con las plantillas integradas (sin avisos).
Sin migración.

Preparación
-----------
1. cd frontend; pnpm build; cd ..
2. Arranca la app en su propia ventana: uv run --directory backend cai start
3. Ten un CV generado de una oferta aprobada (o usa la demo: $env:CAI_DATA_DIR = "data-demo").

Pasos
-----
1. Ficha de la oferta → «CV» → renderiza con cada plantilla integrada (ats-simple, clasica-foto,
   moderna-2col).
   → Con un CV normal de una página, ningún aviso de maquetación.
   → Si sale alguno, abre el PDF y mira la página que dice: ¿es real? Apúntalo.
2. Si tienes plantillas importadas (import-cv-template), renderiza con ellas.
   → Con dos columnas, si salta «Texto del PDF incompleto» por el orden de lectura, es real: un
     ATS leería primero la barra. `docs/CV_TEMPLATES.md` §Avisos explica cómo arreglarlo.
3. Fuerza un CV largo: en «CV», «Máximo de páginas» 2 y un contenido que pase de una página (o
   quita una sección oculta).
   → Si la segunda página tiene dos líneas: «Última página casi vacía» con «Página 2 · Hay que
     recortar contenido…». El render sigue pudiéndose marcar «Usar este para enviar».
   → «Generar CV» con tu agente: el redactor recorta lo menos relevante para la oferta y el aviso
     desaparece.
4. La carta: «Carta» → renderiza con carta-simple y con la plantilla del CV.
   → Sin avisos de maquetación con una carta normal.
5. Demo y eval (opcional):
      $env:CAI_DATA_DIR = "data-demo"; uv run --directory backend cai eval cv
   → La tabla trae «Sin avisos de maquetación del PDF» por caso.

Si algo falla
-------------
- Un falso positivo: pásame el PDF (sin datos tuyos, la demo vale) y el aviso. Los umbrales están
  en `layout` de `config/policies.yaml`; con `enabled: false` se apagan.
