Fase 24.4 · Elegir y cambiar de agente desde la UI: prueba manual
=================================================================

Qué se prueba: la sección «Agentes» de la página «Agente», el agente por defecto, el agente y el
modelo por acción, el desplegable «con Claude Code ▾» de cada botón y que la siguiente ejecución
usa lo elegido, en terminal y en segundo plano. Los tests automáticos ya lo comprueban con agentes
falsos; esto es para verlo con los tuyos (Windows). Basta con Claude Code; con un segundo agente
instalado (Codex, OpenCode o Qwen Code) se prueba también el cambio.

Preparación
-----------
1. Migra tu base de datos: uv run --directory backend alembic upgrade head
   (o simplemente `cai start`, que migra al arrancar)
2. cd frontend; pnpm build; cd ..   (la UI compilada que sirve `cai start`)
3. Arranca la app en su propia ventana: uv run --directory backend cai start

Pasos
-----
1. Página «Agente» → sección «Agentes» al final.
   → Una tarjeta por agente: versión o «No instalado» con la orden de instalación y «Copiar»;
     insignias (Open-source, MCP, Subagentes aislados (nivel A/B), Segundo plano…); las que
     están «sin comprobar» salen con borde discontinuo y «?».
   → Claude Code: «Los subagentes (roles) usan haiku / sonnet…». Codex, OpenCode y Qwen: «heredan
     el modelo de la sesión».
2. «Agente por defecto»: déjalo en «Automático». En la tabla «Por acción», la columna «Efectivo»
   dice «Claude Code · el primero instalado» (o «por CAI_AGENT» si lo tienes en el .env).
3. En la tarjeta de Claude Code, escribe el modelo `sonnet` y pulsa Intro → «Guardado.».
   Inicio → «Buscar ofertas» (o cualquier botón): se abre la terminal con
   `claude --model sonnet "Usa el skill…"`. En esa terminal: `echo $env:CAI_CLIENT_NAME` → claude.
   Borra el modelo y pulsa Intro para dejarlo como estaba.
4. Escribe un modelo con espacios (`son net`) → sale un error en rojo y no se guarda.
5. El desplegable (▾) de un botón dice «con Claude Code». Si tienes otro agente instalado, abre
   «Solo esta vez, con: Abrir con <otro>» → se abre ese agente; la tabla sigue diciendo Claude Code.
   Los no instalados salen deshabilitados con «… no está instalado».
6. Con otro agente instalado, en «Por acción» pon ese agente para «Revisar mi búsqueda» → la
   columna «Efectivo» dice «elegido para esta acción». Embudo → «Revisar mi búsqueda» abre ese
   agente; los demás botones siguen con Claude Code. Vuelve a «Por defecto».
7. En segundo plano: con Claude Code por defecto y un modelo en su tarjeta (p. ej. `haiku`),
   Inicio → «Procesar ofertas» ▾ → «En segundo plano» (necesita `cai worker`, que ya arranca
   `cai start`). En «Agente», la ejecución dice «Con claude (haiku)».
   Si eliges Codex por defecto, «En segundo plano» sale deshabilitado con el motivo (sin
   `launch.headless`). Déjalo como estaba.
8. Cambia el idioma a inglés: la sección y la tabla se ven en inglés (los motivos detallados del
   servidor se resumen con un texto genérico).

Anota debajo de cada paso, con «→», lo que no cuadre.
