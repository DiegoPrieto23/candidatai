# Fase 09b.3 · Plataformas y búsqueda con navegador

Última de las tres subfases de `dev/prompts/09b-alertas-captura-busqueda.md` (09b.1 → 09b.2 → 09b.3).
Rama `fase/09b-alertas-captura-busqueda`, un commit por subfase. Requiere la 09b.1.

## Contexto
Lee `dev/prompts/09b-alertas-captura-busqueda.md`, `docs/FUENTES_OFERTAS.md` (§Búsqueda con el
navegador del agente y §Interfaz para agentes), `docs/POLICIES.md` §8, `docs/AGENT_INTERFACE.md`,
`docs/AGENTS_COMPAT.md`, `dev/DECISIONS.md` ADR-016 y `.agents/skills/buscar-ofertas/SKILL.md`.

## Objetivo
Que el agente pueda configurar con el usuario las plataformas donde buscar y recorrerlas con su
navegador dando de alta lo que encuentra, con LinkedIn desactivado salvo que el usuario lo active
en la UI.

## Alcance
1. **Esquemas** (`app/schemas/sources.py`): `AgentBrowseSource` (`name`, `platform`,
   `search_urls[]` http(s), `priority`, `access: free|login|blocked`, `allow_agent_browsing`,
   `max_offers`, `notes`) y `SourceRunSummary` (`found`, `created`, `existing`, `incidents[]`,
   `started_at?`, `finished_at?`).
2. **Interfaz para agentes** (MCP y CLI con paridad; el test de paridad debe cubrirlas):
   - `list_sources` / `jh sources list [--kind K] --json`: fuentes con su config (sin secretos) y
     última ejecución;
   - `save_source` / `jh sources save --file F --json`: crea o actualiza (por `name`) una fuente
     `agent_browse`. **Rechaza `allow_agent_browsing: true` en LinkedIn** y no puede cambiarlo si
     ya está activado por el usuario (lo conserva);
   - `record_source_run` / `jh sources record-run ID --file F`: anota en `source_runs` (actor
     `agent`) y avanza `last_run_at`;
   - `add_job_from_text` admite además `source_id?`, `platform?`, `external_id?` (`--source`,
     `--platform`, `--external-id`). Si no viene `external_id`, se intenta con
     `platforms.detect(url)`; `source_id` debe ser de tipo `agent_browse`.
3. **API**: activar o desactivar `allow_agent_browsing` de una plataforma (solo desde la UI; para
   LinkedIn exige `confirm_risk: true` en el cuerpo), prioridad y acceso.
4. **UI «Plataformas»**: lista con prioridad, acceso, búsquedas, última ejecución y resultados
   (encontradas, nuevas, incidentes). El interruptor de LinkedIn muestra el aviso de riesgo para
   la cuenta y pide confirmación.
5. **Configuración**: valores por defecto en `config/policies.yaml` → `agent_browse`
   (`max_result_pages`, `delay_seconds`, `default_max_offers`), cargados en `core/policies.py`.
6. **Skill `buscar-ofertas`**: revisa que lo que dice casa con las herramientas implementadas y
   regenera con `scripts/sync_agents.py`. Permisos de Claude Code para `list_sources` (lectura).

## Fuera de alcance
Candidaturas automáticas, resolver captchas, navegación sin agente (scraping desde el código).

## Criterios de aceptación
- `save_source` no puede activar la navegación en LinkedIn (MCP y CLI, mismo error).
- Paridad MCP ↔ CLI de las tres herramientas nuevas y de `add_job_from_text` ampliada.
- Prueba manual de `buscar-ofertas` con una plataforma de acceso libre.

`buscar-ofertas` con el navegador del usuario) y la explicación al usuario de cómo crear en cada
portal las búsquedas con alerta y el filtro de correo que las lleve a la carpeta configurada.
